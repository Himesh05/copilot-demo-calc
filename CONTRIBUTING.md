# Contributing

1. Comment on an issue to say you'd like to work on it, and wait for a reply.
2. Fork the repo and create a branch named `fix/issue-<number>`.
3. Make your change and add or update a test if it makes sense. Run the tests with `pytest`.
4. Sign off your commits (`git commit -s`).
5. Open a pull request using the template and link the issue with "Fixes #<number>".

Be kind and patient. Reviews may take a day or two.
